МОД: Tesla Overload
ID:   tesla_overload

Что делает: «электрический захват» — вражеские здания рядом с твоими юнитами
глушатся (EMP/блекаут) и получают электрический урон. Пульсирует каждые ~0.75 с.

КАК ВКЛЮЧИТЬ:
  1. Включи "tesla_overload" в Mod Manager (или добавь id в scripts/active_mods.txt),
     Save & Apply.
  2. Начни матч.

КАК ПОЛЬЗОВАТЬСЯ:
  - По умолчанию это АУРА: здание противника бьётся, если оно в радиусе
    8 клеток ОТ твоего/союзного ТЕСЛА-юнита (например, Tesla Tank TTNK).
    Обычная пехота (в т.ч. Conscript) и не-тесловые машины НЕ вырабатывают
    разряд — просто юнит рядом с зданием врага недостаточен.
    Список типов-генераторов задаётся в GENERATOR_TYPES в main.lua.
  - Веди Tesla Tank к штабу/строениям врага — они начнут копить урон и блекаут.
  - Только для теста: поставь DEBUG_MAP_WIDE = true в main.lua, чтобы бить
    по всем вражеским зданиям на карте без подхода юнитов (это чит).

ЧТО ПРОИСХОДИТ:
  - Каждые 45 кадров для зданий в радиусе: Disable(45) (блекаут) + TakeDamage(40).
  - Урон идёт «электрическим» вархедом (WARHEAD, fallback-безопасный) —
    если ID нет в rules, нативная цепочка подберёт замену.
  - Генераторы — только дома игрока/союзников И обладающие типом из
    GENERATOR_TYPES; обычная пехота/техника генератором не является.
  - Вражеские считаются по «не союзник и не Neutral/Civilian/Special».
  - Когда вражеских зданий не осталось — "All enemy structures destroyed!".

ЛОГИ: сообщения с ⚡ в игре; печать [LuaAPI] в LuaAPI.log.

ЗАМЕЧАНИЯ:
  - Это механика, а не чит: работает только вблизи твоей техники.
  - В коде учтена погибель зданий во время пульса (pcall + повторный IsAlive).
  - Если новых вражеских зданий появятся после "victory" — захват возобновится.
