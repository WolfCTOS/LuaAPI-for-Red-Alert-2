МОД: God Mode Spectator
ID:   god_mode

Что делает (по замыслу): полный иммунитет к урону местного игрока через
OnPreDamage + начисление +25000 кредитов каждые 60 кадров.

КАК ВКЛЮЧИТЬ:
  1. Включи "god_mode" в Mod Manager (или добавь id в scripts/active_mods.txt),
     Save & Apply.
  2. Запусти матч.

ВАЖНО / СЕЙЧАС В ОСНОВНОМ НЕ РАБОТАЕТ:
  - Иммунитет построен на событии OnPreDamage, которое в ТЕКУЩЕЙ СБОРКЕ
    НЕ подключено (открытый Milestone 13). Значит урон игроку проходить будет.
  - Начисление денег использует устаревшие глобальные функции
    game_GetLocalPlayer / house_AddCredits — этих биндингов в актуальном API нет
    (сейчас House.GetPlayer() / house:AddCredits()), поэтому вызов завершится
    ошибкой. Ошибка перехватится обёрткой, но денег не будет.

ВЫВОД:
  - Это исследовательский мод времён Milestone 4. Ожидаемого «бога/бессмертия»
    в текущей сборке нет.
  - Если нужен иммунитет/деньги — надёжнее сделать это на Update() через
    House.GetPlayer()/house:AddCredits() (как в других рабочих модах).

ЛОГИ: сообщения не приходят (колбэки не вызываются).
